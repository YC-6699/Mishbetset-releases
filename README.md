# משבצת - תוכנה למחשב

משבצת היא תוכנה פשוטה לניהול הכספים בבית: הכנסות, הוצאות, תנועות קבועות, חובות ומעשר כספים.
התוכנה עובדת על המחשב שלך בלי אינטרנט, וכל הנתונים נשמרים במחשב שלך בלבד.

## הורדה והתקנה

1. נכנסים ל[דף הגרסאות](../../releases/latest) ומורידים את הקובץ שמסתיים ב־`setup.exe`.
2. פותחים את הקובץ. אם ווינדוס מציג "Windows protected your PC", לוחצים על **More info** (מידע נוסף) ואז על **Run anyway** (הפעל בכל זאת). ההודעה מופיעה כי התוכנה לא חתומה בחתימה דיגיטלית בתשלום.
3. ההתקנה לא דורשת הרשאות מנהל.

## מעבר מהאתר לתוכנה

1. באתר, לוחצים בתפריט הצד על **"גיבוי מלא למעבר לתוכנה"** ושומרים את הקובץ.
2. פותחים את התוכנה, ובמסך הפתיחה בוחרים **"בחר קובץ גיבוי מהאתר"**.
3. התוכנה מציגה כמה תנועות, חובות וקטגוריות הועברו. כדאי לוודא שהמספרים נראים נכונים.

## איפה הנתונים נשמרים

הנתונים נשמרים בתיקייה:

```
%APPDATA%\com.mishbetset.app\data
```

בתיקייה `backups` שבתוכה נשמר גיבוי אוטומטי אחד לכל יום (30 הימים האחרונים).
מומלץ להעתיק מדי פעם את התיקייה לדיסק און קי או לענן.
